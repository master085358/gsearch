Готово. Утилита поиска по GitHub построена поверх изученной программы и подключена как скил для Claude Code.

  Что сделано

  1. Модуль поиска github_data_file_fetcher/search/ — поверх существующих кешированных/троттлящихся клиентов:
  - search_repositories() — поиск готовых проектов, ранжирование по звёздам, фильтры по языку/топикам/звёздам/дате/лицензии. Всё нужное
  берётся прямо из ответа REST.
  - search_code() — поиск по исходному коду, группировка совпадений по репозиторию + обогащение метаданными (звёзды, топики, лицензия) через
  батч-GraphQL, чтобы результаты тоже ранжировались.
  - Пагинация с корректной границей >= на лимит 1000 (как требует ваш CLAUDE.md), аккуратная обработка ошибок API.

  2. CLI-подкоманды (точка входа github-fetch):
  uv run github-fetch search-repos "pdf table extraction" --language python --min-stars 500
  uv run github-fetch search-code "SKILL.md" --filename SKILL.md --limit 100 --table
  По умолчанию — JSON в stdout (для агента), --table — для человека.

  3. Скил .claude/skills/find-github-projects/SKILL.md — вы вызываете /find-github-projects и ставите цель («найди готовый проект для X»), а
  Claude Code переводит цель в запросы, оценивает кандидатов (звёзды, свежесть pushed_at, лицензия, архивность), заглядывает в README
  топ-кандидатов через github-fetch api и выдаёт ранжированный список с обоснованием.

  4. Документация — README (раздел «Searching for reusable projects») и проектный CLAUDE.md обновлены.
